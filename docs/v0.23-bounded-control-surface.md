# v0.23 bounded control-surface closure

This document is the finite release boundary for v0.23. It prevents a schema-legal
large identifier from moving work out of bounded LLM context or making a controller
operation impossible to recover.

## Authority classes

| Class | Inline summary | Opaque lookup | Digest-bound detail | Executable selector | Exact retry |
| --- | --- | --- | --- | --- | --- |
| Role and session | context + operations | role/session refs | Role detail chunks | signed compact action ref | same ref/canonical JSON/key after lost response |
| Node | context + operations + pre-wait | node ref | Node/action/inventory chunks | signed compact action ref | same ref/canonical JSON/key |
| Attempt | operations + action result + pre-wait | Attempt ref | Attempt/identity chunks | signed compact action ref | same ref/canonical JSON/key across session replacement |
| Declared outcome | action schema option | outcome ref | outcome-ID chunks | `outcomeRef` | same ref/canonical JSON/key |
| Incident | context + incident index + remediation | Incident ref | Incident/remediation chunks | signed compact incident action | same ref/canonical JSON/key |
| Effect and Resource | pre-wait + remediation + operations | object ref | object/remediation chunks | signed compact action ref | reconcile/apply idempotency |
| Checkpoint, Decision, Action and evidence authority | selected inspect summary | object ref | object chunks | controller action only | same ref/canonical JSON/key |

The same envelope covers aggregate status, payload-free history, frontier, evidence
indexes, Incident/remediation inventories, and Effect continuity. Large Role, Node,
Attempt, Incident, Resource, and Effect values are selected through controller-issued
opaque refs on both CLI and MCP; recovering the original bytes is never a prerequisite
for executing the bound operation.

Every aggregate page is capped at 24 KiB, uses byte packing rather than only an item
count, and binds its continuation to the journal head plus an inventory digest. One
oversized item is replaced by a fixed-length summary whose detail can be reconstructed
and digest-verified without loading it into model context.

## Complexity boundary

Frontier resource capacity, dependency topology, Role capability, Attempt Resource,
Attempt Effect, and Incident repair-successor lookups are built once per query. The
planner must remain linear in graph/runtime input size plus emitted actions; no branch
may re-scan all Nodes, Edges, Resources, Effects, or Incidents for every candidate.

## Release proof

The release matrix uses schema-legal 30 KiB identifiers and a 70 KiB outcome. It checks
context, operations, status, history, frontier, evidence, incident/remediation pages,
direct inspect, action input, action result, digest reconstruction, stale references,
cancellation, large-graph complexity, and exact retry after Role/session replacement.
A final cold review starts
only after this matrix and the ordinary release gates pass.
